# Arby's coordinator timeline

This repository serves a dated, encrypted coordinator chart. A teammate can open the complete chart URL without a GitHub account. The URL fragment contains the decryption key; the base Pages URL shows only the shell. Anyone who receives the complete URL can view the chart, so distribute it through the intended team channel.

Thirsty remains the work-order book of record. The chart is a snapshot and labels its source time. Work-order links open the exact Thirsty record for changes.

## Coordinator email controls

After the complete private chart link opens, **Provider parts email template** is available on demand for any charted Installation work order or a manually entered one. It has no opening cutoff. Its six PICOS-to-myCoke part names are clickable in the rich preview and copy; the plain-text copy includes all six full product URLs. The chart's source date is visible. Suggested provider contacts require an exact charted SP agent/location match; other and manual work orders leave To blank. SP activity dates are unconfirmed. Verify current Installation status, SP assignment, date, contact roles, parts, quantities, and links in Thirsty before ordering.

The coordinator chooses a work order, reviews the editable template, copies the full message, opens an Outlook compose window, pastes the body, verifies it, and sends it personally. The Outlook handoff carries To and subject only. It does not put the body into Outlook, send email, verify the signed-in Outlook account, or confirm draft persistence or delivery. Reopening Outlook may create another unsent draft; check Drafts before retrying. If rich clipboard copy is unavailable, the page supplies full URLs and asks the coordinator to make each part name clickable in Outlook.

The customer milestone action keeps its separate reviewed binding and release rules. Check Sent is unavailable. This page does not create a shared Claim, read Sent Items, or mark a milestone complete. The installed helper is separate from this Pages source, and this candidate does not change it. The chart never sends email automatically.

Private contacts, project tracking URLs, plaintext chart data, decryption keys, signing keys, and binding files stay outside this repository. A customer tracking URL is unique to its project; the tracker site's base URL is not a project link. The `noindex` directive is advisory and does not make public Pages private.

Run `npm test` for the invented-data source tests. The protected chart and copy/navigation controls should also be checked in a signed-out browser before release.
