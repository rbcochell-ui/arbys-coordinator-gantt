# Snapshot provider verified prefill V7 — held source only

This new local V7 candidate preserves V6 and is **untracked, held, and not
imported by Draft PR #2**. The checked-in site still imports V4. V7 has not
been staged, pushed, deployed, enabled, or connected to live Graph.
`runtime_config.mjs` remains Off and contains no tenant, List, or mailbox IDs.
There is no Send action. Do not send any email from this candidate.

For one selected eligible preinstall Installation WO, the first-draft route
requires the owner-approved encrypted Gantt chart and Thirsty overlay; a fresh,
exact protected native WO match for agent, store, ACN, type, service code,
status, and number; signed coordinator identity; and an empty shared Claim
key. It rereads the source before and after Claim. A mismatch in two positive
contact pairs holds before Claim. A changed release, protected row, actor,
selection, or recipient binding cannot quietly change the addressed draft.

| Protected Contacts result | Dated chart candidate | Outlook draft To | Gantt panel |
| --- | --- | --- | --- |
| Current verified pair | Same pair, or no pair | Verified pair | Notes that current verified contacts will be prefilled |
| Missing, unverified, or stale pair | Exact dated pair | Blank | Labels manager and planner addresses as **dated suggestions only**, available for coordinator review and copy |
| Missing, unverified, or stale pair | No exact pair | Blank | Tells coordinator to find and verify both roles |
| Current verified pair | Different positive pair | No draft | Holds for contact mapping review |

The coordinator can edit the unsent Outlook draft, confirm current Thirsty
date/scope and recipients, then decide whether to Send in Outlook. The Claim
and Draft receipt preserve the exact native WO ID, shared dispatch key, and
recipient evidence. Reopening a blank-To draft keeps its review flag. Shared
Claim and Sent Items reconciliation continue to prevent duplicate drafts and
record an attended Send. V7 retains the six exact myCoke links and never
places an order.

The current approved chart still has a **one-WO allowlist** and a 24-hour
source-currentness limit. This local candidate does not widen either. A future
release needs a reviewed chart/overlay, protected WO rows and contact coverage
for the chosen cohort, and per-WO selection allowlist. The independent V5
FORM/Case linkage is not integrated; linking the full case population remains
a release gate. Missing store numbers need a separately reviewed address
fallback. Code-8 relocations, held/completed visits, survey, line run, fire up,
and filter-only visits remain outside the first-draft path.

Run invented local tests here with `node --test tests/*.test.mjs`. They cover
verified prefill, no-chart verified prefill, dated suggestions with blank To,
stale and absent Contacts, positive pair mismatch, six links, shared Claim
dedupe, source drift, and edited Sent receipts. They do not access Microsoft
services or send email. The new V7 source and tests need independent review
before any integration decision.
